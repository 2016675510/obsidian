## 灰平衡怎么做最好

### 1. 评价指标：用 ΔCh（即 ΔF）

- 理想中性灰在 Lab 中 `a*=0、b*=0`；但相纸本身有底色，**实际中性灰要以相纸白场为基准**，即相对纸张底色计算色差，与明度 L* 无关。
- 灰平衡偏差：
$$\Delta Ch(\Delta F)=\sqrt{\Delta a^{*2}+\Delta b^{*2}}$$


- 数值越大灰偏越重；**行业常用临界容差 ΔCh ≤ 2**，低于 2 视为灰平衡合格；ΔCh＞2 说明中性灰偏色，需要调整 CMY（或 YMC）配比。
- 注意：**不要只看 L* 亮度判断灰平衡**，亮度合格不代表中性；重点看 a_、b_ 平面上的偏移方向（偏红 / 绿、偏黄 / 蓝）。

### 2. 灰平衡实施步骤

1. **先完成单色通道线性化**，再做灰平衡；通道阶调没对齐时，灰平衡调不稳。
2. **打印中性灰梯尺**：覆盖高光、中间调、暗调多段（如 10–15 级），每级多块重复；以相纸白场为参考。
3. **逐段测 Lab**，计算每级 Δa_、Δb_、ΔCh，判断偏移方向：
    - a* 正偏红、负偏绿；b* 正偏黄、负偏蓝。
4. **调整通道配比**：针对偏色方向增减对应染料比例（例如偏黄就减黄或补蓝通道，依染料模型定）；高光、中间调、暗调分别调整，不要用一个全局比例拉平。
5. **迭代验证**：调整后重打灰梯尺复测，直到各段 ΔCh ≤ 2（或你定的更严容差），且梯尺上目视无可见色偏。
6. **固化为灰平衡曲线 / LUT**：把各阶调的通道补偿写入线性化或 Profile 前的校正表；换相纸批次、色带批次后要复核。

### 3. 容易被忽略的干扰因素

- **OBA 荧光增白剂**：相纸白场在日光（含 UV）下显蓝白，仪器若关闭 UV 会测出发黄；测色和目视要统一 UV 条件，否则浅调灰平衡判断失真。
- **染料扩散 / 热历史**：同一灰块在不同环境温度、打印节奏下发色不同，灰平衡要在稳定生产条件下调。
- **白场随批次变化**：不同相纸批次底色 a*/b* 不同，灰平衡基准要随白场更新，不能沿用旧批次的配比。
- **观察环境**：目视复核用标准光源（D50/D65 按用途），避免在偏色灯光下判断中性灰。
