
热升华相纸属于**反射式印刷介质**（纸张 / 相纸 + 染料层），不是透射彩色负片、彩色反转片。因此要排除胶片专用状态：

| 状态                  | 适用对象                             | 热升华相纸是否适用             |
| ------------------- | -------------------------------- | --------------------- |
| **Status‑T**        | 反射印刷品、胶印、纸张油墨、分色制版，北美体系          | **首选**，反射影像 / 相纸测量最通用 |
| **Status‑E**        | 欧洲 DIN 体系，反射印刷；红 / 绿通道同 T，蓝通道为窄带 | 次选；设备或标准体系要求欧洲口径时使用   |
| Status‑M            | 彩色负片（透射）                         | 不适用                   |
| Status‑A            | 彩色感光胶片、透明片 / 纸基成色剂               | 不适用                   |
| Status‑I            | 窄带，印刷版材、纸张油墨特殊场景                 | 一般不用                  |
| 视觉密度 / 印刷密度 Type1‑3 | 黑白影像、微泡胶片、卤化银、光学声带               | 不适用                   |

## Status-A 和Status-T选择
核心结论： **如果你全程只用 Status‑A、不和外部 T/E 数据对标、ICC 是靠分光 Lab 而不是密度做，最终 Profile 本身是准的；但密度读数、单色阶调曲线、灰平衡的密度监控逻辑会 “口径错位”，跨设备 / 跨工艺比对时坑很大；如果你的线性化是拿密度作为目标来做，影响就非常明显。**

### 1. Status‑A 的光谱本质

Status‑A 原始设计目标：**卤化银彩色相纸、彩色胶片成色染料（银盐相纸）**，它的 R/G/B 滤光响应是匹配银盐耦合染料的吸收光谱，不是为热升华扩散染料设计的。 Status‑T 才是专门给**反射型彩色印刷 / 染料相纸（含热升华）**的反射密度响应。

> 热升华 Y/M/C 染料的吸收光谱，和银盐成色染料不一样，所以**同一块热升华色块，A 和 T 测出来的密度值、通道间密度比例都不一样**，尤其是蓝通道差异最突出。

### 2. 分两种场景看影响（对你 DTP330 最重要）

#### ✅ 场景 A：你只是拿密度做过程监控，线性化、灰平衡、ICC 全部基于分光 Lab（推荐的正规做法）

影响**不大，不会炸颜色**：

- 分光测色（Lab、光谱）不受 ISO‑5 状态影响；ΔCh 也是用 Lab 算的，和密度无关；
- 你用 Status‑A 只是一个 “内部参考读数”，不拿密度值当拟合目标；
- 只要你**从头到尾固定 A，不中途切 T/E**，自己内部的趋势（染料变深 / 变浅、批次波动）依然可以监控；
- 缺点：这个密度值**不能和行业标准、设备厂商参考值、别人 T 状态的数据对比**，拿到外部看会完全对不上。

#### ⚠️ 场景 B：你直接拿 Status‑A 密度作为线性化目标、用密度去对齐 YMC 灰平衡（很多自研脚本 / 老 RIP 这么干）

**影响很大，会造成灰平衡跑偏、阶调匹配错误**：

1. 你按 A 的密度把 Y/M/C 拉到 “密度相等”，但这个等密度是**银盐染料的等权重，不是热升华染料视觉中性**；
2. 结果：密度表看着对齐了，实测 Lab 的 a*/b * 偏，ΔCh 超标；中间调、暗调灰特别容易偏绿 / 偏蓝；
3. 高光段（受 OBA 影响），A 的蓝通道权重和 T 差异进一步放大，浅灰更容易跑色。

举个直观例子： 同样一个中性灰块，T 状态下 Y=0.42 M=0.40 C=0.41；换到 A 状态，可能变成 Y=0.44 M=0.40 C=0.37。你拿 A 的这组数字去做匹配，视觉上就不是中性。

### 3. 对你的实操建议（DTP330 热升华相纸）

1. **最优：监控密度统一用 Status‑T**，和行业影像相纸体系一致，方便以后对标样、对标机台、对标色带批次；
2. 如果你现在已经整套流程跑在 Status‑A、不想推翻现有脚本：
    - 严禁把 A 密度当成 “标准目标密度”；
    - 线性化拟合的目标改用 L*，灰平衡只用 Lab/ΔCh，**密度只做趋势监控，不做闭环目标**；
    - 所有文档、日志、实验表必须标注：密度状态 = Status‑A，避免后面接手的人误以为是 T；
3. 不要混用：**同一套实验，A、T、E 不要来回切换**，一旦切换，历史密度数据全部作废，不能拿来对比；
4. 补充：ICC 本身不依赖密度状态，只要色靶是分光测的，Profile 颜色是独立的，密度只是辅助质控参数。

### 4. 一句话总结

- 只看 Lab、ΔCh 做灰平衡和线性化，A 能用，只是密度读数不通用；
- 拿密度值做闭环对齐 YMC、做密度目标线性化，**强烈不建议用 A，会把灰平衡调歪**。

如果你需要，我可以给你做一个简单的对比脚本：同一组单色阶调，同时导出 A、T 两套密度，看 Y/M/C 响应曲线差异，量化你这边相纸的偏差。
### 测量前必须固定的条件

1. **测量几何条件**：统一 0/45 或 45/0（影像相纸推荐 45/0，避免镜面反射干扰），所有色靶、所有批次保持一致。
2. **光源 / 观察者**：统一 D50、2°（印刷影像标准）；相纸含荧光增白剂（OBA）时，仪器要固定 UV 成分（开启 UV 模拟日光，或按标准固定 UV 档位），否则白场和浅调 Lab 会漂移。
3. **介质底色**：以本机相纸白场为基准，不要用纸张标称白度代替实测白场。
4. **测量时机**：热升华成像后染料有轻微扩散 / 稳定过程，按固定等待时间（如 10–30 分钟，依机型定）再测，避免初测偏深。
