色域本质上**和原色（主色）的光谱 / 色坐标、混色体系（加色 / 减色）直接相关**；三原色在 CIE 色度图上围成的多边形，就是色域边界，顶点越靠近马蹄形光谱轨迹，色域越大。

区分两个概念：

- **标准色域（色空间，如 sRGB、P3、Adobe RGB）**：是人为定义好原色、白点的标准色域；
- **设备色域**：显示器、相机、打印机实际能做到的色彩范围，受硬件限制

## 一、色域和什么有关

1. **原色的光谱纯度（最核心）** RGB 加色设备：红、绿、蓝发光材料 / 背光光谱越窄、越纯净，原色饱和度越高，色域三角形越大（量子点、OLED 就是靠更纯的光谱做大色域）。 CMYK 减色印刷：油墨 / 染料的吸收光谱，决定原色顶点；油墨越 “干净”、串色越少，色域越大。
2. **原色数量** 三原色是三角形；增加原色（四色、五色、广色域印刷加橙、紫墨），变成多边形，色域可以扩大。
3. **白点（白场）定义** 同一套原色，白点不同，色域形态、可用范围会变；标准色空间都会固定白点（sRGB/D65、印刷 D50）。
4. **亮度 / 动态范围（色域体积）** 二维色度图只看色相饱和度；**三维色域体积**还要受最大亮度、最低黑位限制：很多高饱和颜色只能在特定亮度下再现，亮度拉高饱和会掉，体积变小。
5. **介质（减色体系尤其明显）** 印刷：纸 张白度、光泽、底色；纸张发黄、吸墨，直接压缩色域。
6. **输入侧：传感器的色彩响应（相机 / 扫描仪色域）** 拜耳彩色滤光片的光谱响应曲线，决定相机能捕捉的色域上限。
7. **色彩编码位深（不是决定色域大小，决定色域里的层次）** 8bit、10bit 不改变色域边界，只决定里面能放多少级颜色，位深不足会出现色带。

## 二、哪些因素会影响色域大小（按优先级）

### ✅ 显示设备（加色 RGB）

1. 背光 / 发光材料光谱：CCFL < 普通 LED < 量子点 < 激光光源；光谱越窄越好
2. 彩色滤光片：滤片的截止特性，抑制串色
3. 峰值亮度、黑电平：HDR 对色域体积影响很大
4. 老化：荧光粉、量子点衰减，原色漂移，色域缩水
5. 校准：校色仪校准不会**扩大硬件色域上限**，只会把现有色域还原准确

### ✅ 印刷 / 颜料（减色 CMYK / 多色）

1. 油墨 / 染料种类、纯度（专色、OGV 扩色油墨）
2. 承印物：白度、吸墨性、光泽度
3. 叠印特性、网点工艺

### ✅ 相机 / 扫描仪（采集色域）

1. 感光元件上面 CFA 彩色滤光片光谱响应
2. 镜头色散、IR-cut 红外截止滤镜
3. 光源（拍摄环境光源光谱）

### ✅ 软件 / 色彩管理层面

- ICC 配置文件：只是**描述、映射色域**，不能突破硬件本身色域上限；色域映射（gamut mapping）是把超色域颜色压缩进去，不是扩大色域。
